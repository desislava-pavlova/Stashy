# Stashy Fixes and Changes Plan

Plan 04, started 27/09/2026 (numbered 03 until 10/10/2026). This is the
user's side: updates and fixes to what you see and use ("I don't like the
colour of this button"). It comes after plan 03 (the structure review, the
developer's side) and before plan 05 (the admin's look) and plan 06 (the
.exe).
**Status:** collecting items. No phases yet.

It works in two stages:

1. **Collecting (now).** While plan 03 runs (and plan 02 before it), the
   bugs and changes you notice go into the table below. **Nothing here is
   worked on before plan 03 is done** unless you say "fix R<n> now".
2. **Planning (after 03).** We go through the list together. Unclear items
   get questions, and the rest become phases with checkboxes, a decisions
   log and a DEVLOG entry, the same way as plans 01 and 02. The item table
   then stays at the bottom as the plan's source.

## How to add something

Either write it below yourself, or tell Claude "add to 04: …" in chat. Claude
then only files it here and doesn't start on it. One line is enough. Details
help but aren't required:

- **Where:** which page or feature
- **What happens:** what you saw (a screenshot path in `images/` is fine)
- **What you expected:** how it should be
- **Kind:** bug (something is wrong) or change (works, but should be
  different)
- **Urgent?** Mark it urgent if it blocks you. Claude will then ask whether
  to fix it before plan 03 finishes.

Something that only bothers you in the code, not on screen, goes to plan 03
instead ("add to 03: …").
